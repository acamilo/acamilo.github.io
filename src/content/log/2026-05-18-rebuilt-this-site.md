I did a refresh of the site. It now has a blog, where I'll post about whatever
I'm currently building, mostly hardware with some software in the mix.

Most of it was written by an AI coding assistant. I set the direction and
reviewed the output. It's a small Jekyll site with no theme or framework,
plain CSS, and no JavaScript. It's responsive and follows the system light or
dark setting.

GitHub Pages builds and serves it from the repo. Adding a post or project is
one Markdown file and a `git push`.
